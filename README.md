# AuraWalls 🌟
### 4K Auto Wallpaper & Editor

> *Your Mood, Your Wallpaper — Fully Automated.*

## Features
- 🌟 Aura Score Personality Engine
- 🌤️ Weather + Time Auto Theme
- 🎊 Festival Mode (Eid, Puja, Christmas...)
- 🎨 Live Filter Editor (Blur, Brightness, Grayscale)
- 🎨 Color Palette Extractor
- ❤️ Favorites System
- ⬇️ One-Tap Download
- 🔄 Auto Wallpaper Changer
- 🖼️ Set Home / Lock / Both

## Tech Stack
- Platform: Android (Java)
- APIs: Pexels, Unsplash, Pixabay
- Libraries: Retrofit, Glide, WorkManager, AdMob
